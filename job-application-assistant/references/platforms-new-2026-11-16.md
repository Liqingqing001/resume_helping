# 新增招聘网站：2026-11-16 实测

适用于网易、得物、金山办公、360、科大讯飞、商汤、米哈游、莉莉丝、MiniMax、联想。这里只记录公开入口、控件适配和核验方法；账号资料、偏好、简历全文及逐站回执留在使用者自己的私有工作区。更新简历不等于提交职位申请。

## 飞书招聘：得物、莉莉丝、MiniMax

- 入口分别为 `https://careers.dewu.com/index/`、`https://lilithgames.jobs.feishu.cn/career/`、`https://vrfi1sk8a0.jobs.feishu.cn/379481/`。页头 `.topbar-userMobile` 悬停后出现“我的简历”；使用实际菜单链接进入，不从职位的“立即投递”建档。
- 菜单实际进入各站的 `/resume/view`；无简历时会跳到 `/resume/edit`。本轮三个站均完成独立个人简历保存与刷新核验，未投递岗位。
- 附件 `input[data-cy=inputUpload]` 上传后，点击“解析并覆盖”才会填表。先备份原字段；空白简历才可直接解析覆盖。上传成功和解析完成都不代表在线简历已保存。
- Formily 标签和控件带 `data-form-field-id`。本轮解析将本科识别成“其他”、项目名称夹带“在线演示”、项目链接丢失，须纠正。重复卡片中的公司、职位、日期、描述、项目链接分别核对。
- 学历选择使用当前控件已绑定 `options`，按 `label` 查找选项后调用该控件的变更回调；不得把某站的选项编号套到别站。生产页面本轮存在 `__reactInternalInstance$…`，不要只查新版本的 `__reactFiber$…`。
- “完成”保存个人简历，正常返回预览并显示最近更新时间。刷新后核对附件名、学历、教育区间、每段经历、项目正文及链接，再记成功。

## 北森：360、科大讯飞

- 入口 `https://360campus.zhiye.com/`、`https://iflytek.zhiye.com/`。账号菜单 → 我的简历 → `/form` → “编辑简历”，与投递记录独立。本轮均保存并刷新核验通过。
- 顶部“拖拽或点击上传简历，我们帮你快速解析”与下方“简历附件”是不同控件。解析可能同时生成附件，必须在保存后的预览验证，不能以解析成功推断附件已持久保存。
- 重复条目以 `.form-item label` 及其所属 `.form-part` 定位。解析可能合并多个项目、串错项目标题与时间；先拆成正确条数，再逐条修正。科大讯飞当前个人简历模板没有独立“项目经历”，有“在校实践”，可以如实承载对应实践项目，避免伪装成受雇经历。
- 文本框 DOM 的值不一定同步业务模型。已观察行级组件 `cmp_name/cmp_label/onChange`，正常字段回调接收 `{value,text}`。按当前行的真实绑定更新，多个字段之间等待渲染后重新取绑定；最后走页面“保存”和验证，不改校验规则。
- 地区弹窗中的文字可能只用于展开下级，选择图标与“确定”也是分开的。读取本次站点实际候选节点的 `data.id/label`，不要猜地区编码、复制其他站的学历/地区编号或把只展开城市当成已选择。回读地区标签证明保存。
- 日期按网站控件支持的月份精度填写。持续经历使用本条真实“至今”勾选；可提前实习可能额外要求最早入职日，使用用户确认的到岗规则。
- 科大讯飞个人简历可保存真实毕业时间，但模板提示的校招届别仍须在正式申请前核对。个人简历保存成功不等于符合当前校招资格。

## 网易

- `https://hr.163.com/` 登录后，页头 `#area` 悬停 → 我的简历 → `/user.html/resume/display`。“编辑个人信息”进入 `/user.html/resume/modify`，附件与当前雇主、相关链接在此维护。
- 已有单附件时，新上传可能因数量上限被拒绝；先保留旧文件或可恢复的引用，确认替换控件后删除旧附件，再用当前实际的 `input#resumeAppendixList` 上传。已有文件时隐藏输入框的 ID 可能不同，每次以当前 DOM 为准。
- 保存要求本页隐私政策确认框。确认上传文件名和字段回显后再保存。本轮附件、个人信息、教育、两段实习及两个项目均已保存并刷新核验。
- 经历卡片 `.u-hotpost` 悬停才出现“编辑/删除”。需要等上一条正常保存、编辑表单关闭后再添加下一条，不能在未保存的旧条目上继续填新公司。
- 日期控件本轮要求精确到日。源资料只有月份时，先取得使用者的日级补齐规则；保留原始月份精度，补齐日不得反写成已确认事实。不要为了保存编造持续经历的离职日期。
- 工作性质为必填，按实际选择实习/全职；同属工作经历不等于全职。新增条目的按钮是“确定”，已有条目是“保存”，不要在按钮不存在时直接认定保存成功。只写开始时间的区间不能据此宣称持续条目已保存。
- 当前控件无可用“至今”时，只有使用者明确授权，才可用本次资料更新截至日，并在正文说明仍在职/进行中、不是实际离职或结束日期。本轮此方式已保存并刷新核验；源资料继续保留持续状态。

## 米哈游

- `https://jobs.mihoyo.com/` 的“切换到校招”进入校园/实习渠道；账号下拉 → 我的简历。独立个人简历中的“保存并预览”与职位投递不同。
- 上传 PDF 会提示“是，解析并替换/否，仅上传附件”。先备份再选择。解析可能把集团背景识别成真实雇主、把项目名变成“在线演示”、漏掉学历及项目职务，须按来源纠正。
- AntD 控件 ID 如 `resumeInfo_*`、`educations_*`、`practices_*`、`projects_*`。选项按当前绑定的 label 取值；日期使用本页已有日期对象及控件正常回调，不跨站套用值编码。
- 保存可能要求验证简历邮箱。交由本人收取验证码；框未关闭或提示“验证码无效”时不能记成功。验证通过后核对最近更新时间、预览及刷新结果。本轮附件和在线简历均已保存并刷新核验。
- 空白的可选游戏经历条目可以删除；不得编造游戏名称、时长或成就。校招与实习面向人群按岗位详情分别核验。

## 金山办公 Moka

- `https://join.wps.cn/campus-recruitment/wps/41436` 是宣传入口；从站内“实习生招聘”等真实链接进入 `https://app.mokahr.com/campus-recruitment/wps/41436`。宣传页打开不表示候选人系统已登录。
- 登录后头像菜单 → 我的简历 → `#/candidateHome/resume`。本轮该页呈现在线表单；独立附件入口尚未验证，不通过正式职位申请来凑附件上传。
- 姓名、手机号、邮箱可能由候选人账号注入并禁用编辑。值缺失时去“个人资料”核对，让本人完成必要的邮箱绑定/验证，不解锁禁用控件或用组件状态越过账号流程。
- 本轮账号资料补齐后，在线教育、实习、项目、日期与个人主页均正常保存，刷新后的业务模型已核验。当前仍未发现独立 PDF 附件控件，附件记为未完成，不能把在线保存当成 PDF 已上传。
- 旧式 Moka 简历模型可见 `basicInfo/educationInfo/practiceInfo/projectInfo/uploadInfo`；只能在本页确认相同结构后适配。隐藏的安全验证组件不代表当前操作受阻，凭实际可见状态判断。

## 联想

- `https://talent.lenovo.com.cn/account/resume` 为独立“我的简历”。“上传简历”里的解析勾选、确认保存，以及后续“确定解析”是不同步骤。解析会清空已有在线字段，先备份再操作。
- 各 `.el-form` 按分区单独保存。已验证附件、个人信息、教育、已结束的实习/项目、技能及信息来源可分别保存；完整度变化只作提示，不能替代逐项回读。
- 部分经历/项目结束时间当前为必填，未观察到“至今”选项；持续条目不能虚构结束日期。此类未保存条目单独记待处理，附件已保存也不等于整站在线简历已完成。
- 经使用者明确授权，可在上述持续条目的正文说明仍在职/进行中，并将系统结束月份解释为本次资料更新截至日。没有授权时不默认套用。完整度即使达到100%，也要检查未关闭的编辑表单、条目数量和刷新后正文。
- 本轮最终刷新遇到 `/gateway/proj/status` 等接口500，主页面只剩聊天助手。登录检查返回200，不应因此让使用者重复登录；记录网站加载故障，复用原连接做有界恢复核查，不能在页面未恢复时记刷新核验通过。
- 英语成绩、校园大使、亲属任职、岗位/地点调剂等分别读取使用者自己的确认值。未知项集中确认，不把某一使用者的选择设成所有人的默认值。信息来源/推荐码按使用者提供的信息填写。
- “去投递简历”属于申请流程入口，不作为个人简历的保存按钮。
